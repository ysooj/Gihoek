# 연령대별 타겟 분석 및 대응 설계

본 문서는 연령 구분 용어 제안 → 연령대별 게임 성향 → 핵심 타겟 재정의 → 타겟 대응 요소 → 비타겟 유입 포인트 순으로 구성된다.

---

## 1️⃣ 연령층 구분 용어 제안

| 구분        | 연령대   | 기획서용 용어 제안 |
| --------- | ----- | ---------- |
| 유치생       | ~6세   | 유아층        |
| 초–중등      | 7~13  | 아동 플레이어층   |
| 중–고등      | 14~18 | 청소년 플레이어층  |
| 고등–성인(MZ) | 19~39 | MZ 게이머층    |
| 40~60대    | 40~59 | 중장년 게이머층   |
| 60대 이상    | 60+   | 시니어 게이머층   |

※ 기획서에서는 ‘~층’ 표현이 가장 무난하고 전문적임

---

## 2️⃣ 연령대별 게임 성향 분석 (게임 일반 기준)

### 🔹 유아층

* 선호 장르 : 캐주얼, 학습형, 직관적 조작
* 이해 방식 : 시각·반복 중심
* 플레이 시간 : 짧고 단편적
* 결제 성향 : 보호자 의존

**요약** → 게임을 ‘놀이’로 인식, 서사·시스템 이해도 낮음

---

### 🔹 아동 플레이어층 (초–중등)

* 선호 장르 : 액션, 어드벤처, 성장형 RPG
* 이해 방식 : 명확한 목표·보상 구조 선호
* 플레이 시간 : 방과 후 중심, 비교적 규칙적
* 결제 성향 : 낮음 (부분적 과금)

**요약** → 성취감·캐릭터 성장·직관적 재미 중시

---

### 🔹 청소년 플레이어층 (중–고등)

* 선호 장르 : 스토리형 RPG, 선택 기반 게임, 경쟁 요소
* 이해 방식 : 시스템·서사 동시 이해 가능
* 플레이 시간 : 시험 기간 제외 시 집중 플레이
* 결제 성향 : 제한적이나 선택적 소비 가능

**요약** → 감정 이입, 선택 결과에 민감, 서사 몰입도 높음

---

### 🔹 MZ 게이머층 (고등–성인)

* 선호 장르 : 내러티브 게임, 인디, 실험적 구조
* 이해 방식 : 해석·메타적 의미 중시
* 플레이 시간 : 불규칙하나 몰입 시 장시간
* 결제 성향 : 완성도 높으면 지불 의사 높음

**요약** → ‘경험’과 ‘의미’에 비용과 시간을 투자

---

### 🔹 중장년 게이머층 (40~60대)

* 선호 장르 : 퍼즐, 전략, 추억 기반 IP
* 이해 방식 : 단순 구조 선호
* 플레이 시간 : 짧고 간헐적
* 결제 성향 : 안정적이나 보수적

**요약** → 복잡한 UI·텍스트에 피로도 큼

---

### 🔹 시니어 게이머층 (60+)

* 선호 장르 : 두뇌 훈련, 캐주얼
* 이해 방식 : 매우 직관적 구조 필요
* 플레이 시간 : 짧고 느긋
* 결제 성향 : 낮음

**요약** → 게임을 ‘취미 활동’으로 인식

---

## 3️⃣ 내 게임의 핵심 타겟 재정의

🎯 **타겟 범위 : 아동 플레이어층 ~ MZ 게이머층**

### 타겟 공통 특성

* 스토리를 ‘따라가는 것’ 이상으로 경험함
* 선택이 결과로 이어지는 구조에 흥미
* 캐릭터 감정·관계 변화에 민감
* 화려함보다 몰입을 우선
* 긴 플레이보다 ‘기억에 남는 순간’을 중시

---

## 4️⃣ 타겟을 겨냥한 게임 내 요소 매핑

### ✔ 아동 플레이어층 대응

* 직관적인 전투·탐색 구조
* 명확한 UI (자아 마모도 색 변화)
* 텍스트 최소화, 연출 중심 전달

### ✔ 청소년 플레이어층 대응

* 선택 왜곡 구조
* NPC 반응 변화
* 보스 페이즈 연출을 통한 감정 고조

### ✔ MZ 게이머층 대응

* 자아 마모도 시스템의 메타적 의미
* 엔딩 분기와 해석 여지
* ‘착함’이라는 개념에 대한 문제 제기

👉 하나의 시스템을 연령별로 다르게 소비 가능

---

## 5️⃣ 비타겟층이 느낄 수 있는 재미 요소

### 🔸 중장년 게이머층

* 스토리 중심 플레이 흐름
* 도트·쯔꾸르 스타일의 향수
* 복잡하지 않은 조작

### 🔸 시니어 게이머층

* 명확한 목표 구조
* 전투 부담이 낮은 진행 방식
* 감정 드라마로서의 감상 재미

비타겟층에게도 ‘게임’이 아닌 **짧은 이야기 경험**으로 접근 가능

---

## 6️⃣ 기획서용 요약 문장

본 게임은 아동 플레이어층부터 MZ 게이머층까지를 핵심 타겟으로 설정하며,
직관적인 플레이 구조 위에 감정·선택·해석을 중첩한 설계를 통해
연령에 따라 다른 깊이의 경험을 제공하는 것을 목표로 한다.
